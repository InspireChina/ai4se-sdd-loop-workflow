## 计划正文结构

正文按版块组织。只输出上面角色里列出的版块，没列出的版块不要补。每个版块内部按下列小节顺序写；版块内不涉及的小节保留标题并写「无」或「不涉及」，不得省略。

### 版块 A：后端实现计划（仅当后端相关时输出）

#### A1. 工程实现结构
- 仓库 / 服务 / 模块划分（本次新增或改动的服务/模块，落到具体目录）
- 包结构（新增包、改动包的层级与职责）
- 分层调用约束（哪层可调哪层、禁止反向依赖等；与仓库现有分层一致）

#### A2. 详细模型与数据设计
- **新增表**：表名、字段、类型、索引、约束；不涉及则写「无」
- **已有表更新**：表名、新增/修改字段、迁移说明；不涉及则写「无」
- 关键实体关系（必要时附简短 ER 说明）

#### A3. 接口清单
按 `method + path + 描述 + 入参 + 出参` 列出，并分三类、分对内/对外：
- **新增 API**、**已有 API 修改**（标注入参/出参/行为）、**完全复用的 API**
- **对内**与 **对外** 分开列

#### A4. 消息与事件契约
- 新增/修改的消息主题、事件名、payload 结构、生产方/消费方；不涉及则写「无」

#### A5. 核心状态机与流程图
- 状态流转用 mermaid `stateDiagram-v2`；业务流程用 mermaid `flowchart`
- 不涉及状态机则写「无」，但只要有流程就画 mermaid

#### A6. 核心业务规则与具体实现
只列实际用到的：算法与落点、外部依赖契约与场景、实际读写的表与字段及业务含义、复用的既有逻辑与改动点、与验收标准的对应关系。

#### A7. 新增或修改的配置
- 配置项名、含义、默认值、影响范围；不涉及则写「无」

#### A8. 数据迁移与初始化方案
- 迁移步骤、初始化数据、回滚方案；不涉及则写「无」

#### A9. 并发与一致性方案
- 分布式锁、幂等、事务边界、一致性策略；不涉及则写「无」

#### A10. 性能与容量方案
- 缓存、限流、批量、异步、容量预估；不涉及则写「无」

#### A11. 安全与权限
- 鉴权、数据权限、敏感数据、审计；不涉及则写「无」

### 版块 B：前端实现计划（仅当前端相关时输出）

#### B1. 工程实现结构

#### B2. 页面与路由

#### B3. 组件清单

#### B5. 接口契约（与后端联调）

- 用 mermaid 画关键操作流程，含加载/成功/失败/空态；不涉及则写「无」

#### B7. 核心业务规则与具体实现
